# Кинозал — фильмы прямо в Discord

Свой плеер внутри голосового канала, как встроенное «Смотрим вместе», только для любых фильмов по ссылке.

- Все в канале смотрят одно и то же место фильма.
- Пауза и перемотка у одного происходят у всех.
- Работает на компьютере и на телефоне.

Фильмы берутся по ссылке:

- прямая ссылка на файл MP4 или WebM;
- публичная ссылка на файл на **Яндекс Диске** (там бесплатно 5–10 ГБ).

Кинозал работает бесплатно на Cloudflare Workers: банковская карта не нужна.

> Показывайте только фильмы, на которые у вас есть права: свои записи, фильмы в общественном достоянии и т.п.

## Как пользоваться

Есть два способа:

- **Сеанс по расписанию.** В Discord откройте настройки кинотеатра → «Добавить сеанс» и вставьте ссылку на видеофайл
  или Яндекс Диск. Когда сеанс начнётся, бот напишет в афишу с кнопкой **«Смотреть в кинозале»**.
- **Прямо сейчас.** Зайдите в голосовой канал и напишите `/kinozal ссылка`.

Ссылки на YouTube по-прежнему открываются во встроенном «Смотрим вместе».

Внутри кинозала любой зритель может вставить ссылку на другой фильм: кнопка «Сменить фильм».

## Установка (один раз, около 15 минут)

### 1. Аккаунт Cloudflare

Зарегистрируйтесь на [dash.cloudflare.com/sign-up](https://dash.cloudflare.com/sign-up). Это бесплатно.

### 2. Развернуть кинозал

Нужен Node.js (`winget install OpenJS.NodeJS.LTS`). В папке `cinema`:

1. Установите зависимости:
   ```
   npm install
   ```
2. Войдите в Cloudflare — откроется браузер, нажмите «Allow»:
   ```
   npx wrangler login
   ```
3. В файле `wrangler.toml` впишите в `CLIENT_ID` Application ID бота
   (Developer Portal → ваше приложение → General Information).
4. Задайте секрет — придумайте длинный пароль из латинских букв и цифр:
   ```
   npx wrangler secret put KINOZAL_SECRET
   ```
5. Опубликуйте кинозал:
   ```
   npx wrangler deploy
   ```

В конце появится адрес вида `https://kinozal.<имя>.workers.dev` — это адрес кинозала.

### 3. Включить кинозал в Discord

[Developer Portal](https://discord.com/developers/applications) → приложение бота:

1. **Activities → Settings**: включите **Enable Activities**.
2. **Activities → URL Mappings**: в строке **Root Mapping** (префикс `/`) укажите адрес кинозала без `https://`,
   например `kinozal.имя.workers.dev`. Нажмите **Save**.

### 4. Подключить к боту

Панель управления → **Функции → Кинотеатр**:

1. Впишите **Адрес кинозала** и **Ключ кинозала** (тот же секрет, что в шаге 2).
2. Нажмите **Сохранить**, затем **Перезапустить сейчас**.

## Если не работает

| Проблема | Что сделать |
|---|---|
| Кнопка «Смотреть в кинозале» не появляется | Проверьте адрес и ключ в панели. Ссылка в сеансе должна быть не на YouTube |
| Кинозал открывается, но видео нет | Нужен MP4 (H.264) или WebM. Ссылка Яндекс Диска должна быть публичной и вести на файл, а не на папку |
| «Не удалось открыть кинозал» | В Developer Portal не включены Activities или не задан Root Mapping |
| Нет звука | Нажмите на видео: браузер включает звук только после нажатия |

## Как устроено

- `public/` — страница плеера (`app.js`). `sdk.js` — Discord Embedded App SDK 2.5.0, собранный в один файл (MIT).
- `src/worker.js` — сервер на Cloudflare:
  - синхронизация зрителей (Durable Objects, WebSocket);
  - фильм для голосового канала, его сообщает бот;
  - передача видео с поддержкой перемотки.
